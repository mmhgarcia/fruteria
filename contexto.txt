ANÁLISIS DEL PROYECTO FRUTERÍA POS
===================================

NOMBRE DEL PROYECTO: fruteria-pos-pwa
VERSIÓN: 1.0.0
AUTOR: Cognition (según estructura)
LICENCIA: Comercial (ver LICENSE)

DESCRIPCIÓN:
Punto de Venta táctil para fruterías, carnicerías y charcuterías en Venezuela.
100% offline-first. Sin internet. Sin backend. Solo tu negocio.

ESTADO: 🚧 En desarrollo activo

TECNOLOGÍAS PRINCIPALES:
- Frontend: React 18.2.0
- Build Tool: Vite 5.0.8
- PWA: vite-plugin-pwa 0.19.0
- Generación PDF: jsPDF 4.2.1, jsPDF-autotable 5.0.8
- TypeScript: @types/react, @types/react-dom
- Mobile: Capacitor 8.5.0 (Android, iOS)

ESTRUCTURA DEL PROYECTO:
=======================

Directorios principales:
- src/ - Código fuente de la aplicación
  - components/ - Componentes React (30+ archivos)
  - data/ - Datos estáticos (products.js, ramos.js)
  - features/ - Funcionalidades organizadas por feature
    - TasaBcv/ - Gestión de tasa de cambio BCV
  - hooks/ - Custom hooks React
  - utils/ - Utilidades y servicios (db, logService, session, etc.)
- public/ - Recursos estáticos
- dist/ - Build de producción
- docs/ - Documentación del proyecto
- BrainStorm/ - Roadmap y análisis de features

COMPONENTES PRINCIPALES:
=======================

Componentes de UI:
- App.jsx - Componente principal (509 líneas)
- Header.jsx - Cabecera con carrito y búsqueda
- ProductGrid.jsx - Grid de productos

Modales:

- SalesReportModal.jsx - Reporte de ventas

- Categories.jsx - Gestión de categorías

Configuración:

- RamosComerciales.jsx - Gestión de ramos comerciales

CARACTERÍSTICAS FUNCIONALES:
============================

Core:
- Interfaz 100% táctil con grandes botones
- Gestión de productos por categorías
- Carrito de compras con edición de cantidades
- Pagos mixtos: Pago Móvil, Punto, Efectivo ($ y Bs), Divisa
- Tasa de cambio BCV actualizable
- Ticket digital imprimible con desglose por método de pago

Seguridad:
- PIN de administrador con hash SHA-256
- Sistema de sesiones con tiempo configurable
- Bloqueo tras 3 intentos fallidos
- Badge de alertas para logs no leídos

Gestión:
- Ramos comerciales: frutería, carnicería, charcutería
- CRUD de categorías jerárquicas por ramo
- CRUD de productos
- Histórico de tasas BCV
- Sistema de logs (INFO, WARNING, ERROR, FATAL, ALERT)
- Backup y restauración de datos

Reportes:
- Reporte de ventas
- Productos más vendidos con ranking
- Tickets diarios
- Exportación a PDF

PWA:
- Instalable como app nativa
- Funciona completamente offline
- Service Worker con Workbox

ARQUITECTURA TÉCNICA:
====================

Persistencia de datos:
- IndexedDB para datos principales (productos, ventas, logs)
- localStorage para carrito, tasa, configuración y sesión

Servicios:
- db.js - Operaciones IndexedDB (getProducts, addSale, updateProduct, etc.)
- categories.js - Gestión de categorías
- logService.js - Sistema de logging
- session.js - Gestión de sesiones de seguridad

Custom Hooks:
- useLocalStorage - Hook para localStorage con persistencia

Configuración Vite:
- watch con polling para WSL (intervalo 300ms)
- PWA con autoUpdate
- Manifest para instalación standalone
