## Propósito

Guía para el dueño o administrador del negocio sobre configuración y gestión del POS:

- Gestión de productos y categorías
- Configuración de ramos comerciales
- Tasa de cambio BCV
- Administración de usuarios (PIN)
- Backup y restauración
- Reportes de ventas
- Personalización de colores y nombre
